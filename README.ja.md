# vector-png ファイル形式仕様

[English](README.md)

## なぜ vector-png が必要なのか

PNG は、多くのアプリで表示でき、共有や貼り付けに便利です。しかし、通常の
PNG に書き出すと、図形や文字などを個別に編集するためのベクター情報は残りません。
後から修正するには元の SVG や制作アプリのファイルを別に保管し、画像と対応づけて
管理する必要があります。共有した PNG だけが手元に残ると、編集元を探したり、
図を作り直したりすることになります。

**vector-png は、表示用の PNG と編集元の SVG を一つのファイルにまとめます。**
通常の画像ビューアーでは PNG として表示でき、対応ツールでは埋め込まれた SVG を
取り出して編集し、画像と一緒に更新できます。たとえば、資料に使った図の色や形を
後から変えたいときに、元ファイルを別途探す手間を減らせます。

この仕様は、その仕組みをアプリ間で共有するためのものです。共通の保存形式が
あれば、制作・共有・再編集を異なるツールでつなぐ実装を作れます。
SVG で表現できる範囲の再編集を目的とし、制作アプリ固有の全機能や編集履歴の
保存は保証しません。また、画像編集ソフトや共有サービスが埋め込みメタデータを
削除すると、SVG による再編集はできなくなります。

## このリポジトリについて

SVG を圧縮 iTXt に埋め込んだ PNG の、**アプリに依存しないドラフト仕様**です。
Codex スキルや Illustrator／Inkscape 拡張の実装とは分けて管理します。

- [正式な仕様本文（英語・wire v1／draft 0.1）](SPEC.md)
- [日本語仕様ガイド](SPEC.ja.md)
- [安全な SVG の対応プロファイル](profiles/safe-svg-v1.md)
- [実装・相互運用のガイド](IMPLEMENTATIONS.md)
- [共通サンプルとテスト](fixtures/README.md)

[既存の Python CLI／Codex スキル](https://github.com/makotosan/vector-png) は
別リポジトリの参照実装です。将来の Illustrator／Inkscape 版は Python や
CairoSVG に依存せず、この仕様を基に実装できます。アプリ向け拡張自体は未実装です。

「保存形式として正しい」「安全な SVG の範囲に対応する」「再描画した画素が一致する」
を区別します。**CairoSVG の完全画素一致は共通形式の必須条件ではありません。**

Python 3.10 以降の標準ライブラリだけで共通サンプルを検証できます。

```sh
python -m unittest discover -s tests -v
python tools/build_fixtures.py --check
```

仕様はドラフトです。英語の SPEC.md を正とし、日本語ガイドは理解を助ける資料です。
